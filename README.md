### [doit.md](./projetos/doit.md)

Criei o doit.md para reunir notas, tarefas, projetos e calendário no mesmo aplicativo. É uma **PWA**, um aplicativo web que pode ser instalado no computador ou no celular, com editor Markdown, checklists e organização por pastas.

O projeto inclui integração com Google Calendar e uma ferramenta de linha de comando para sincronizar as notas com arquivos locais.

## Como trabalho

Antes de programar, procuro entender quem vai usar o sistema e o que precisa acontecer em cada situação. Registro as regras e decisões no repositório e confiro as mudanças com testes e uso da aplicação.

Nos projetos atuais, uso agentes de IA para apoiar a implementação e a revisão. O Meu Negócio Fácil foi desenvolvido sem IA. O [BuilderFlow](./projetos/builderflow.md) reúne os arquivos que criei para manter o contexto entre as sessões de desenvolvimento.
